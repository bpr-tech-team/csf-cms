# Agents

This project uses the Payload CMS skill at `.agents/skills/payload/`.
Start with `.agents/skills/payload/SKILL.md` for a quick reference, then see `.agents/skills/payload/reference/` for detailed docs.

## Git

Не создавай коммиты самостоятельно. Создавать git-коммиты можно только по
явному запросу пользователя. Запросы на исправления, реализацию функций
или настройку деплоя сами по себе не разрешают создавать коммиты.

# Контентные иконки

Общее поле `contentIcon()` используется в ServicesGrid, ProductsGrid, HomepageHero.quickLinks и branchInfo. Для новых блоков используйте эту же фабрику и компонент `ContentIcon` (или `CardIcon` с подложкой).

В CMS выбирается источник: изображение из медиатеки или Font Awesome Free. Каталог открывается по кнопке, поддерживает поиск по английским названиям и алиасам, фильтры Solid / Regular / Brands, постраничный просмотр. Рядом показываются варианты 32 px для карточки и 44 px для hero.

Загруженные изображения сохраняют исходные цвета по умолчанию. В одноцветном режиме прозрачность изображения служит маской для цвета блока; используйте SVG или PNG с прозрачным фоном. Непрозрачный фон также будет окрашен. Настройка масштаба 75–125% корректирует видимый размер рисунка, не меняя размеры его контейнера.

Font Awesome хранится в локальных npm-пакетах. Серверный реестр `fontAwesome.server.ts` выдаёт каталог через `/api/content-icons` и отдельный SVG через `/api/content-icons/{solid|regular|brands}/{name}`. Полный набор SVG не включается в клиентский JavaScript. Идентификаторы проверяются по реестру на сервере; произвольные URL вместо идентификаторов не допускаются.

Иконки Font Awesome Free предоставлены Fonticons, Inc. по CC BY 4.0: https://fontawesome.com/license/free. Атрибуция включена в каждый выдаваемый SVG и в каталог CMS.

Миграция `20260924_163153_content_icons` заменяет старые upload-поля группами без переноса выбранных иконок, в том числе в версиях страниц. Старые медиафайлы не удаляются. После применения нужно заново выбрать иконки в контенте. Откат восстанавливает структуру старых полей, но не прежние значения.

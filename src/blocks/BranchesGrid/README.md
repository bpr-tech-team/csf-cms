# Контакты и филиалы

## Страница `/kontakt`

Создайте стандартную страницу со slug `kontakt` и блоками в таком порядке:

1. `contactHero`: заголовок, описание, фон из макета и телефон. Кнопка «Volat» звонит на этот номер, «Napsat» ведёт к `#kontakt`.
2. `branchesGrid`: заголовок и упорядоченный список ссылок на страницы филиалов. Для сетки из макета задайте трём первым карточкам ширину `standard`, двум последним — `wide`. Расписание можно скрыть для отдельной карточки.
3. Существующий `logoMarquee`.
4. Существующий `centeredCta` со ссылкой на `#kontakt`.
5. Существующий `processSteps`.
6. Существующий `formBlock`, оформление `homepageDark`, якорь `kontakt`.

Header и Footer настраиваются в существующих глобальных настройках.

## Страница `/kontakt/{slug}`

Создайте страницу типа **Pobočka**. Slug содержит только имя филиала, например `hradec-kralove`; префикс `/kontakt/` добавляется автоматически.

Во вкладке **Pobočka** заполните адрес, телефоны и email. Реквизиты, расписание, иконка карточки и карта необязательны. Эти данные используются и в карточке списка, и в `branchDetails`: повторно вводить их в блоках не нужно.

Добавьте `branchHero`, затем `branchDetails`. `branchHero` и `contactHero` — самостоятельные блоки со своими полями и компонентами. Hero должен быть первым и единственным на странице. Блоки `branchHero` и `branchDetails` доступны для сохранения только на страницах типа Pobočka.

Для интерактивной карты в Google Maps выберите **Sdílet → Vložení mapy**, скопируйте только значение `src` из iframe в поле **Google Maps – URL pro vložení**. Полный HTML и обычная ссылка на место не подходят. Без URL карта не выводится.

Названия, slug, содержимое блоков, адрес и подписи расписания переводятся через переключатель локали. Строки расписания общие для языков: переводите существующие строки, не удаляя их и не создавая заново. Английский маршрут — `/en/kontakt/{slug}`.

На публичном сайте список показывает только опубликованные филиалы. Изменение, снятие с публикации или удаление филиала обновляет кэш списков. CMS-ссылки, preview, SEO и sitemap учитывают новый маршрут.
